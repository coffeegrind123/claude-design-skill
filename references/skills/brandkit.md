# Brandkit — identity boards & logo systems

For briefs asking for a **brand kit, identity system, logo concepts,
brand-guidelines board, or identity deck**. The deliverable is a curated
multi-panel board (a logo cover, construction, applications, color, type,
essence) either rendered as generated imagery or laid out as an HTML
artifact. The core discipline: **meaning before marks** — the symbol
comes from brand strategy, never from a random icon grab.

## Source

Distilled from [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)
(MIT) — `skills/brandkit/SKILL.md`.

## 1. Brand strategy first

Before generating anything, infer: category · audience · product
function · emotional promise · cultural position · trust level · visual
world · symbolic metaphor · what the brand should avoid. The visual
system must be based on meaning. Map category → symbol logic
deliberately:

| Category | Core ideas | Symbol logic |
|---|---|---|
| Developer tool | building, speed, precision, control | cursor, frame, bolt, scaffold, grid |
| AI assistant | delegation, intelligence, clarity | spark, orbit, signal, path, node |
| Security | protection, vigilance, boundary | shield, eye, seal, protected core |
| Voice AI | sound, rhythm, command, flow | waveform, mic, orb, speech path |
| Compliance | trust, order, rules | seal, badge, document, shield |
| Drone / robotics | flight, control, vision, mission | wing, owl, crosshair, path |
| Luxury / editorial | taste, material, ritual, restraint | monogram, seal, paper, emboss |
| Productivity | focus, momentum, clarity | path, check, block, light |

## 2. Logo standard

The mark should be simple, memorable, symbolic, scalable, ownable,
visually balanced, and usable as icon / wordmark / badge / UI mark /
pattern. It should feel like it came from research and reduction. **Avoid**
generic lightning bolts, random animals, fake luxury crests, copied
famous marks, overcomplicated symbols, clipart, meaningless sparkles, and
inconsistent variants.

**Concept methods — use one, combine at most two:**

1. **Monogram + meaning** — the brand initial fused with a metaphor
   (`S` + soundwave, `A` + ascent). Use negative space, cuts, folds, or
   geometry; never a boring letter-in-a-box.
2. **Product action** — turn the main verb into a symbol (build → frame /
   scaffold; protect → shield; speak → waveform; automate → loop).
   Abstract and premium, not literal.
3. **Metaphor fusion** — two ideas reduced into one readable mark (owl +
   drone vision, shield + mountain, moon + waveform). Subtle.
4. **Negative space** — empty space creates the intelligence (hidden
   arrow, protected center, cutout initial, eye from crossing shapes).
   Keep it crisp.
5. **Construction geometry** — build the mark from a clear system
   (circles, diagonal cuts, grids, frames, modular blocks, orbital
   paths, measured linework). One panel can show the construction logic.

## 3. Default 3×3 panel board

A strong board reads as a curated sequence, not nine equally loud tiles.
Vary panel weight: a large calm cover, one digital mockup, one image-led
atmosphere panel, one system/construction panel, one physical/icon
application, one quiet tagline panel.

1. **Logo cover** — the primary mark, large, calm.
2. **Logo construction** — grid / geometry behind the mark.
3. **Digital application** — the mark in a product UI / app icon.
4. **Brand essence** — the one-line idea or mood.
5. **Color system** — palette swatches with roles.
6. **Typography** — display + text specimen.
7. **Physical application** — signage, card, packaging, or merch.
8. **Image direction** — the photographic / illustrative world.
9. **System detail** — a pattern, iconography, or motion note.

Alternate layouts when 3×3 doesn't fit: 2×3, 2×2, 1×3, 4×2.

## 4. Mode presets

Pick the mode from the strategy, then hold its cues and palette:

- **Dark developer / builder** — graphite surfaces, terminal-green or
  electric accent, mono type, grid/scaffold cues.
- **Dark product / operator** — near-black, one cool accent, dense
  precise UI, control-panel feel.
- **Dark nature / calm system** — deep green/teal, organic curves,
  restrained glow.
- **Security / threat intelligence** — high-contrast dark, alert accent,
  shield/eye/crosshair motifs, disciplined and serious.
- **Light editorial / compliance** — paper background, ink text, one
  restrained accent, hairline rules, authoritative.
- **Luxury / beauty / fashion** — bone/smoke or deep monochrome, monogram
  or seal, generous negative space, material/emboss cues.
- **Voice / communication** — waveform/orb motifs, rhythmic layout,
  soft-but-precise.
- **Cultural / experimental** — expressive type, unexpected color,
  poster energy — only when the brief invites it.

## 5. Discipline

- Sparse, intentional typography; strong symbolic meaning over decoration.
- Disciplined palette (a few roles, not a rainbow).
- Premium, art-directed mockups — not generic device frames floating in a
  gradient.
- All the `anti-ai-slop.md` rules apply: no purple-glow defaults, no emoji
  marks, no placeholder brand names, no meaningless sparkles.

## Pre-flight

- [ ] Brand strategy inferred (category → symbol logic) before any mark
- [ ] Logo uses 1 (max 2) named concept methods and is grounded in meaning
- [ ] Board follows the 3×3 (or a named alternate) with varied panel weight
- [ ] A single mode preset chosen and held across every panel
- [ ] One disciplined palette, sparse type, no AI-slop tells
